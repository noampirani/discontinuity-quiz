# עדכון המשחק: גרף על מסך התוצאות, בלי הסברים כתובים

מבוסס על גרסת 10 השאלות האחרונה, עם סגירת חדר, שינוי תשובות, תוצאות הכיתה ודירוג ידני.

## מה עודכן

- **שאלה 10:** הוסר העיגול הריק שמסמן את הנקודה `(0,0)`. ערך הפונקציה בפועל (`f(0)=1.8`) עדיין מסומן בנקודה מלאה. הגרף המתנודד נשאר.
- **מסך «איך ענתה הכיתה?»**: מציג את הגרף של השאלה לצד מספר הצודקים/טועים/מי שלא ענו והתפלגות הבחירות. התשובה הנכונה מסומנת, אך אין הסבר מילולי — אפשר לבקש מסטודנט להסביר בעל פה.
- **הוסרו ההסברים המילוליים** גם ממצב משחק אישי, מצב הקרנה וסיכום שאלות.
- **הדירוג נשאר ידני**: מסך התוצאות נשאר עד לחיצת המתרגל על «המשך ל-Leaderboard».

## התקנה

1. פתחו את https://github.com/noampirani/discontinuity-quiz
2. החליפו *רק* את `index.html` ו־`live.js` בקובצי העדכון, ישירות בשורש המאגר.
3. בצעו Commit changes והמתינו ש-GitHub Pages יפרסם את האתר.
4. רעננו את https://noampirani.github.io/discontinuity-quiz/?teacher=1 עם Ctrl+Shift+R, או פתחו מחדש בספארי.

**לא משנים את** `firebase-config.js`, את כללי Realtime Database או את Authentication.

## בדיקה

בדיקות דפדפן עם Firebase מדומה; לא בוצעה בדיקה מול מסד Firebase החי.
