# עדכון המשחק: בלי ספירות בזמן מענה; מעבר ידני לדירוג

עדכון זה מבוסס על גרסת **10 השאלות עם סגירת חדר**. הוא משאיר את המנגנון הקיים של Firebase, שמירת הניקוד, תיקון התשובות, קוד QR ואיפוס חדר.

## מה השתנה

1. **בזמן שהסטודנטים עונים**, אין תצוגת מספר ההצבעות או ההתפלגות שלהן — גם לא במסך המתרגל שעשוי להיות מוקרן בכיתה. כל סטודנט עדיין רואה את *הבחירה האישית* שלו ויכול לשנות אותה עד לחשיפת התשובה או לתום שעון השאלה.
2. אחרי שלוחצים **"חשוף תשובה וניקוד"**, מוצגים הפתרון, ההסבר, מספר הצודקים, השוגים ומי שלא ענו, וההתפלגות בין האפשרויות.
3. **מסך הפתרון לא עובר אוטומטית.** גם אחרי 5 שניות או 5 דקות הוא נשאר פתוח. למתרגל יש כפתור **"🏆 המשך ל-Leaderboard ←"**.
4. רק לחיצה על הכפתור מעבירה את כל המשתתפים לפודיום ולדירוג. כפתור **"לשאלה הבאה"** מופיע לאחר הצגת הדירוג; בשאלה האחרונה מופיע **"סיום המשחק"**.
5. **שעון 30 השניות לשאלה עצמה לא השתנה.** אם הוא מופעל, תום הזמן עדיין חושף את הפתרון; הזמן הבלתי מוגבל מתייחס לשלב שאחרי החשיפה.

## התקנה (כמו בעדכון הקודם)

1. פתחו את https://github.com/noampirani/discontinuity-quiz
2. העלו והחליפו **רק** את `index.html` ואת `live.js` שבתיקייה הראשית של המאגר.
3. לחצו **Commit changes**, המתינו לפרסום GitHub Pages ורעננו את האתר עם `Ctrl + Shift + R`.
4. היכנסו ממסך המתרגל: https://noampirani.github.io/discontinuity-quiz/?teacher=1

**לא צריך להחליף את `firebase-config.js`, לשנות Realtime Database Rules או לגעת ב־Firebase Authentication.**

## בדיקות

בדיקה מקומית בדפדפן עם חיקוי Firebase אישרה: אין ספירות בזמן בחירה אצל המתרגל או הסטודנט, נתוני התוצאות מופיעים בחשיפה, התוצאות נשארות לאחר יותר מחמש שניות, לחיצה ידנית מציגה Leaderboard, ולאחריה אפשר להתקדם לשאלה הבאה. לא בוצעה בדיקה מול מסד Firebase האמיתי.
