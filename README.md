# עדכון: תוצאות השאלה ואז Leaderboard

הגרסה הזו שומרת את המשחק, תשעת הגרפים, קוד החדר, ההצטרפות בכינוי, ה־QR ושינוי התשובה כמו שהם.

## מה חדש

1. בלחיצה על **חשוף תשובה וניקוד** מוצג לכולם מסך תוצאות גדול: כמה צדקו, טעו ולא ענו, וכן התפלגות ההצבעות, התשובה הנכונה וההסבר.
2. **אחרי חמש שניות בדיוק** מסך התוצאות מתחלף אוטומטית ל־**Leaderboard** עם פודיום לשלושת המקומות הראשונים. סיכום התוצאות נשאר מוצג גם מעל הפודיום.
3. למתרגל יש כפתור **הצג דירוג עכשיו**, שמדלג על ההמתנה ומסנכרן את המעבר אצל כל המשתתפים.
4. מעבר לשאלה הבאה נשאר בשליטת המתרגל בלבד. ההשהיה מסונכרנת לפי שעת Firebase, ולכן גם רענון או התחברות מאוחרת מציגים את השלב הנכון.

## איך מעדכנים את GitHub Pages

1. חלצו את קובץ ה־ZIP ופתחו את המאגר שלכם ב־GitHub.
2. החליפו **רק** את שני הקבצים `index.html` ו־`live.js` ברמה הראשית של המאגר ואשרו **Commit changes**.
3. **אין צורך לגעת ב־Firebase או ב־firebase-config.js או ב־database.rules.json**. כל כללי האבטחה הקיימים ממשיכים לפעול.
4. המתינו לדקה או שתיים לפרסום ב־GitHub Pages, רעננו עם `Ctrl+Shift+R` ופתחו את הקישור למתרגל:
   `https://noampirani.github.io/discontinuity-quiz/?teacher=1`

## בדיקה קצרה

פתחו חדר במחשב והצטרפו אליו בטלפון. התחילו שאלה, ענו בטלפון ולחצו 'חשוף תשובה וניקוד' במחשב. בדקו תחילה שמופיע מספר התשובות הנכונות והשגויות, ולאחר כחמש שניות מופיע הפודיום.
