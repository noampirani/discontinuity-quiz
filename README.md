# עדכון המשחק: סגירת חדר באמצע + 10 שאלות

זהו עדכון לגרסת המשחק הכיתתי שכבר פועלת אצלכם ב-GitHub Pages וב-Firebase. **יש להחליף רק את הקבצים `index.html` ו-`live.js`.**

## מה השתנה?

1. **כפתור "🗑️ סגור חדר ואפס משחק" למתרגל** – הכפתור מופיע בחלק העליון של מסך המתרגל, כולל במסך ההמתנה, במהלך שאלה, אחרי חשיפת הפתרון ובסיום המשחק. הוא אינו מופיע לסטודנטים.
2. בלחיצה מוצגת **בקשת אישור** לפני פעולה בלתי הפיכה. אחרי אישור, החדר כולו נמחק מ-Firebase – כולל המשתתפים, התשובות והניקוד. המשתתפים בחדר הישן יקבלו הודעה שהחדר נסגר.
3. המתרגל חוזר למסך **"יצירת חדר חדש"** ויכול להתחיל מחדש עם קוד חדר חדש. לסיום טסטים אין צורך לערוך את מסד הנתונים ידנית.
4. נוספה **שאלה 10**, מסוג אי־רציפות סליקה: הגרף של `x·sin(1/x)` כאשר `x ≠ 0` ו-`f(0)=1.8`. אף שהגרף מתנודד סביב האפס, בגלל `|x·sin(1/x)| ≤ |x|` הגבול הוא 0.
5. כל המונים, ההתקדמות ומסך הסיום הותאמו ל-10 שאלות. שינוי תשובה, חשיפת תוצאות הכיתה ואחריהן Leaderboard נשארו ללא שינוי.

## העלאה ל-GitHub

1. פתחו את המאגר: https://github.com/noampirani/discontinuity-quiz
2. העלו והחליפו את **שני הקבצים בלבד**: `index.html` וגם `live.js` בתיקייה הראשית של המאגר; שמרו באמצעות **Commit changes**.
3. המתינו לפרסום ב-GitHub Pages ורעננו באמצעות `Ctrl + Shift + R`.
4. היכנסו כמתרגל: https://noampirani.github.io/discontinuity-quiz/?teacher=1

**לא צריך לשנות את `firebase-config.js`, את כללי Firebase או את הגדרות Authentication.** כללי ה-Realtime Database הקודמים מאפשרים ליוצר החדר למחוק אותו.

## חשוב

- **סגירת החדר מוחקת את כל הנתונים שבו לצמיתות.** אם רוצים רק לעזוב את מסך המתרגל ולחזור אליו מאוחר יותר, משתמשים ב-"יציאה למסך הראשי" במקום בכפתור האיפוס.
- לאחר סגירת חדר ה-QR והקוד הישן כבר אינם פעילים. יש לשתף את **ה-QR החדש** לאחר יצירת חדר חדש.
- מומלץ לבצע ניסיון קצר במחשב ובטלפון לפני התרגול בכיתה. הבדיקה המקומית של העדכון נעשתה במסד נתונים מדומה, לא מול פרויקט Firebase האמיתי שלכם.
