# משחק אי־רציפות — בחירת מסביר ואנימציות לדירוג

עדכון לגרסה הקיימת של 10 שאלות עם חדר כיתתי, QR, שינוי תשובה, סגירת חדר, פתרון ידני ודירוג.

## מה חדש

1. **בחירת סטודנט שיסביר:** לאחר שחושפים את הפתרון מופיע למתרגל כפתור ״בחר/י מסביר באקראי״. הוא מגריל כינוי רק מבין הסטודנטים שהשיבו נכון לשאלה הנוכחית. ניתן להגריל שוב (בלי לחזור על אותו סטודנט עד שכל העונים נכון נבחרו), או להסתיר את השם. אם אין תשובות נכונות, הכפתור מושבת. הבחירה מתבצעת בדפדפן של המתרגל, ללא שמירת הכינוי שנבחר במסד הנתונים, והיא **לא מוצגת במסכי הסטודנטים**. שימו לב: אם מקרינים את *כל מסך המתרגל*, השם יהיה גלוי גם על ההקרנה.
2. **Leaderboard חגיגי:** אחרי שלוחצים ידנית על מעבר לדירוג, הפודיום נכנס באנימציה ויש אפקט קונפטי קצר. מוצג גם ״מטפס/ת השאלה״ — מי שעלה הכי הרבה מקומות ביחס לדירוג בסוף השאלה הקודמת. בשאלה הראשונה אין נתון קודם להשוואה. במקרה של שוויון במספר המקומות שהושגו, מוצגים כל המטפסים המובילים. דירוג בעלי אותו ניקוד נקבע לצורך ההצגה על פי סדר הכינויים, ולכן שינויי מקום יכולים לכלול הכרעת שוויון כזו.
3. **סיום חגיגי:** אנימציית פודיום גם בסיכום הסופי.

הגרפים, עשר השאלות, הצגת ההצבעות רק *אחרי* החשיפה, מסך התוצאות ללא הסבר כתוב, מעבר ידני ל־Leaderboard, חדרים כיתתיים ו־QR נשמרו.

## איך מתקינים

1. פותחים את https://github.com/noampirani/discontinuity-quiz
2. מחליפים **רק** את `index.html` ואת `live.js` בקבצים שבתיקיית העדכון — ישירות בשורש המאגר.
3. מבצעים **Commit changes** וממתינים עד לפרסום ב־GitHub Pages.
4. פותחים מחדש או מרעננים את https://noampirani.github.io/discontinuity-quiz/?teacher=1

**לא משנים את** `firebase-config.js`, את כללי Realtime Database או את הגדרות Authentication. העדכון הזה אינו דורש שינוי ב־Firebase.

## בדיקות

בוצעו בדיקות עם דפדפן Chromium ועם סימולציה של Firebase: בחירת מסביר מתוך עונים נכון, הגרלות חוזרות ללא חזרה, הסתרת השם במסך הסטודנט, אנימציות דירוג, זיהוי עלייה בדירוג בשאלה 2, מסך סיום אחרי 10 שאלות ותצוגת טלפון ללא גלילה אופקית. **לא בוצעה בדיקה מלאה מול Firebase האמיתי.**
