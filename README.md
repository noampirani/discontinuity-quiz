# משחק אי־רציפות — גרסה כיתתית משודרגת

9 שאלות עם גרפים, קוד חדר, כינויים, התפלגות תשובות, שינוי תשובה, QR ופודיום של המקומות 1–3.

## עדכון מאגר שכבר מחובר ל־Firebase

**חשוב: אל תחליפו את `firebase-config.js` במאגר שלכם!** הוא כבר מכיל את פרטי Firebase שהגדרתם. החבילה הזו מכילה רק את קובצי העדכון.

1. הורידו את קובץ ה־ZIP וחלצו את תוכנו.
2. פתחו את המאגר ב־GitHub, והחליפו את **`index.html` ו־`live.js`** בקבצים החדשים. אפשר להעלות אותם דרך **Add file → Upload files** ולאשר החלפת הקבצים. אפשר גם לפתוח קובץ, ללחוץ על עיפרון, ולהחליף את תוכנו. ודאו ששניהם נמצאים בשורש המאגר (ליד `firebase-config.js`). בצעו **Commit changes**.
3. ב־Firebase Console, בתוך **Realtime Database → Rules**, החליפו את כל תוכן העורך בתוכן הקובץ החדש `database.rules.json` ולחצו **Publish**. הקובץ ב־GitHub אינו משנה אוטומטית את הכללים בענן. **שלב זה הכרחי כדי ששינוי תשובה יעבוד**.
4. המתינו לפרסום ב־GitHub Pages ורעננו את הדף בעזרת **Ctrl + Shift + R**.

## כתובות כניסה

- **מתרגל בלבד:** `https://noampirani.github.io/discontinuity-quiz/?teacher=1` — פותח את מסך יצירת החדר. רצוי לשמור כסימנייה במחשב שלך.
- **סטודנטים:** סורקים את ה־QR שמוצג במסך חדר ההמתנה של המתרגל; נפתח קישור עם `?room=ABC123` (הקוד האמיתי יוחלף אוטומטית). העמוד מציג רק התחברות עם כינוי וקוד חדר; **ללא כפתור ״למתרגל״**.
- אפשר לתת גם `https://noampirani.github.io/discontinuity-quiz/` ולהזין קוד ידנית, בלחיצה על **הצטרפות למשחק כיתתי**.

**אבטחה:** הפרדה בין קישור המתרגל לקישור הסטודנטים היא הפרדת ממשק, *לא* סיסמת גישה. אדם שמכיר את `?teacher=1` יכול לפתוח חדר משלו, אך לא לנהל את החדר שפתחתם: כללי Firebase מאפשרים לשנות את פרטי החדר רק לחשבון האנונימי שיצר אותו. אם נדרש שרק משתמש מזוהה אחד יוכל ליצור חדרים, יש להוסיף Authentication נפרד למתרגל וכללי הרשאות לפי זהותו.

## מה חדש במשחק?

1. **שינוי תשובה** — כל סטודנט יכול ללחוץ על אפשרות אחרת שוב ושוב במהלך השאלה. רק הבחירה האחרונה נשמרת. לאחר חשיפת התשובה (או תום 30 שניות, אם שעון פעיל) הבחירה נעולה.
2. **תוצאות נכונות ושגויות** — המתרגל רואה במהלך השאלה התפלגות מצביעים, ללא סימון התשובה הנכונה. אחרי החשיפה כולם רואים מספר שצדקו, מספר שטעו, ומספר שלא ענו, וכן כמה בחרו בכל סוג אי־רציפות. בסיום מופיע סיכום לפי כל אחת מ־9 השאלות.
3. **QR להקרנה** — כאשר המתרגל יוצר חדר, נוצר קוד QR גדול המציג את כתובת ההצטרפות עם קוד חדר מוכן. קוד ה־QR מוצג בחדר ההמתנה, ומוסתר בזמן השאלות כדי להשאיר מקום לגרף. בנוסף יש כפתור העתקת קישור הזמנה.
4. **פודיום 1–2–3** — בתום כל שאלה מופיעים בעלי המקומות הראשונים, עם 🥇🥈🥉. הניקוד 100 לתשובה נכונה; אין בונוס למהירות. במקרה של שוויון מוצג אותו ניקוד.

## בדיקה מהירה לפני השיעור

1. פתחו במחשב המתרגל את הקישור עם `?teacher=1`, לחצו ״יצירת חדר״ וראו QR וקוד חדר.
2. פתחו את הקישור שסרקתם בטלפון (או חלון גלישה בסתר), ובחרו כינוי.
3. התחילו שאלה, בחרו תשובה בטלפון ואז *שנו אותה* לפני חשיפת התשובה.
4. חשפו במחשב ובדקו שמוצגים ספירות נכון / לא נכון / לא ענו ופודיום.
5. בסוף המשחק אפשר למחוק את החדר. מחיקת החדר מוחקת את התשובות והכינויים.

## מגבלות

- דרוש אינטרנט ו־Firebase Realtime Database. ספריית QR נטענת מ־cdnjs; אם אינה זמינה, יש ניסיון גיבוי משירות QR חיצוני, ואפשר תמיד להקליד את קוד החדר ידנית.
- כללי Firebase החדשים משמרים את תיקון ההצטרפות הקודם, ומשנים רק את ההרשאה לעדכון תשובה קיימת בזמן שהשאלה פתוחה.
- הסטודנטים בוחרים כינוי ואין אימות זהות; אין להשתמש בניקוד כציון רשמי. כל מי שמחזיק בקוד חדר יכול לקרוא את נתוניו, ומי שרוצה יכול לבדוק את הפתרונות בקוד הפתוח, ולכן זה מתאים לתרגול כיתתי בלבד.
